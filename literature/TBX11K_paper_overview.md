\n## TBX11K dataset Overview

TB is a serious infectious disease that causes millions of deaths worldwide annually. Due to the lack of training data, using computer vision for TB detection is difficult. The previous largest public TB dataset had only around 600 X-ray images. To solve this data problem, the TBX11K dataset was introduced in this paper. It contains 11.2k X-ray images with corresponding bounding box annotations for TB areas.Since TB is fatal and contagious, it is critical to diagnose it as early as possible, but there are some challenges. Diagnosing TB early requires advanced laboratories and can take a long time. Another issue is that even expert radiologists can detect TB with only 68% accuracy compared to the golden standard because of faint and small patterns. For these reasons, deep CNNs are required to detect TB and assist radiologists.

The size of this dataset is about 17 times larger than the largest existing dataset at that time. Also, this dataset has annotated bounding boxes for TB areas along with image-level annotations, enabling it to recognize TB as well as identify affected areas to help radiologists with detailed diagnosis. This dataset has four categories: healthy, active TB (late stage), latent TB (early stage), and unhealthy but non-TB, making it more suitable for real-world scenarios. Each X-ray image in TBX11K is tested using the golden standard (i.e., diagnostic microbiology) and then annotated by experienced radiologists from major hospitals. Highly experienced radiologists performed the bounding box annotations for the dataset, along with cross-checking by other radiologists. The labeled TB types were also double-checked to ensure that they matched the labels produced by the golden standard.The dataset is split into train, validation, and test sets in a ratio of 3:1:2. Existing object detectors have issues with the CTD task and lead to many false positives. Therefore, instead of only using existing object detectors, this paper reformulates well-known object detectors for simultaneous X-ray classification and TB area detection. The classification branch learns to classify X-rays into three categories: healthy, sick but non-TB, and TB using Softmax. The detection branch learns to detect TB in two categories, latent and active, along with their locations. To achieve this, the convolutional layers of object detectors such as VGG16 and ResNet-50 are modified.

Training is divided into two phases because training everything together can be unstable. In the first phase, only the detection branch is trained using only the TB-positive images from TBX11K in order to learn TB localization. In the second phase, the detector is frozen and only the classification branch is trained using TBX11K (TB, healthy, and sick but non-TB), along with a random half of the MC and Shenzhen datasets and the DA and DB datasets, to learn X-ray image classification.The evaluation is performed using six metrics: accuracy, AUC-ROC, sensitivity, specificity, average precision, and average recall. For the classification task, when ImageNet pretraining is enabled, Faster R-CNN achieves the best performance, while without pretraining, SSD achieves the best performance. Faster R-CNN achieved 91.2% sensitivity and 89.9% specificity, while all tested deep learning models surpassed radiologists in accuracy (68%). These results suggest that AI-based TB detection from chest X-rays has strong potential for practical use.For the detection task, only the positive X-ray images were used. SSD achieved the best performance in most cases, except for evaluation using all X-rays with ImageNet pretraining, where Faster R-CNN achieved the best performance.

While this paper shows significant performance improvements over radiologists and provides a much larger dataset compared to previously used datasets, it still has some limitations. Most latent TB targets were correctly localized but incorrectly classified as active TB, which, according to the paper, was caused by the limited number of latent TB samples. Therefore, this class imbalance problem should be addressed in future work. Additionally, although the detector could identify target regions, the localization was not very accurate.
